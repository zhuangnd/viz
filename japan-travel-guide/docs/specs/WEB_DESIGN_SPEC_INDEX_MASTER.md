## 一、系统设计核心目标与原则

1. **信息架构优化与视口高度释放（Global Header 重构）**：
   - 彻底解决原有版本在导航栏堆叠 6–12 个长按钮导致的垂直空间过度侵占、视线遮挡与折行混乱问题。
   - 将 `global-header` 严格压缩为 **50px 单行紧凑固定栏**，设立四大清晰分区（品牌区、路线抽屉触发区、双模交通切换区、功能工具组）。
   - 引入 **Top Sliding Route Drawer（顶部展开式路线抽屉矩阵）**，将 12+ 条路线按四大规划模态分栏收纳，兼具优雅交互与极致空间利用率。
2. **业务组件升级（以 `route-meta-grid` 代替 `kpi-grid`）**：
   - 摒弃仅停留在宏观数据的旧版 `kpi-grid`，借鉴 `v2.html` 的行动导向型 `route-meta-grid`，直接呈现「建议总天数」、「推荐铁路通票」、「交通组织骨干」与「起讫城市枢纽」，并配合 SVG 图标提供高价值出行决策信息。
3. **引入物候热力与季节指引系统（`seasonal-box` + `phenology-box`）**：
   - 将 12 个月适行热力胶囊与季节建议卡片动态绑定，随选定路线实时切换，深度融入 2026 最新官方气候数据（如 1–2 月豪雪应对与温泉重点、9–10 月无红叶实情辟谣与徒步指南）。
4. **视觉风格与微质感对齐 `v2.html`**：
   - 全面引入 `v2.html` 的和风现代排印体系（Noto Serif SC / Noto Sans SC / JetBrains Mono）与日本传统色系（Navy/朱砂红/松叶绿/琥珀金/和纸白）。
   - 采用精致的 6px/8px 圆角、细微边框线（1px solid var(--slate-200)）与轻量投影，确保在全屏桌面与移动端均呈现高品质画册（Editorial Cartography）质感。
5. **绝对零 Emoji 规范**：
   - 页面与代码中 100% 采用内联精密 SVG 图标，禁止任何廉价表情符号出现。

### 响应式断点适配（Breakpoints）
- **桌面大屏 (>= 1200px)**：43% (左栏) / 57% (右栏) 严格固定分屏，左栏独立原生滚动，右栏地图高度自适应填满视口。
- **平板设备 (768px – 1199px)**：50% / 50% 等分分屏，高程剖面图高度微调至 130px。
- **移动端 (< 768px)**：自动折叠为单栏上下流式布局。顶部为 45vh 地图与轻量剖面，底部为抽屉滑动式详细卡片，支持手势上滑查看详情。

## 三、Global Header 信息安排与路线抽屉设计方案

针对用户特别指出的“压缩区块大小和信息密度，避免占用过多页面，对路线、模式、版本、主题切换、提示信息等合理分类分区，考虑用抽屉/折叠式展示路线”需求，执行如下工程设计：

### 3.1 导航栏四大分区架构

```text
+------------------------------------------------------------------------------------------------------+
| [Zone A: 品牌识别]   [Zone B: 路线抽屉中心 + 双模切换]               [Zone C: 实用指南]  [Zone D: 引擎/版本]|
| (SVG Mark + 标题)    (路线总览选择器 ▼  |  公共交通 ⇄ 自驾)         (规制/交通/食宿/备忘) (底图/暗色/版本矩阵) |
+------------------------------------------------------------------------------------------------------+
```

1. **Zone A（左侧品牌区，宽度约 220px）**：
   - 品牌 Mark：和风印章样式「日」字方印。
   - 标题组合：`日本深度自助旅行` + 版本微章 `2026 MASTER`。
   - 紧凑布局，字体采用 `Noto Serif SC` 粗体，行高收紧。
2. **Zone B（中央操作区，宽度自适应居中）**：
   - **路线抽屉触发按钮 (`#btn-route-drawer`)**：
     - 外观：类似精美胶囊按钮，包含路线图标 + 当前选中路线名称（如 `经典一：东海道黄金三角 (18D)`）+ 下拉三角形 Chevron。
     - 徽章指示：展示该路线所属分类色点（如蓝色代表落地框架，深绿代表经典长线，金棕代表文学寻踪）。
     - 点击动作：触发顶部路线抽屉（Top Route Drawer）平滑滑下。
   - **双模交通切换胶囊 (`.mode-switch-capsule`)**：
     - 尺寸紧凑（高度 28px），采用细边框分段控制（Segmented Control）：
       - `模式A: 公共交通+eBike`
       - `模式B: 合规租车自驾`
     - 切换时平滑改变背景色，并即时更新全局时间线卡片内容与地图行车线样式。
3. **Zone C（功能与指南模态入口组，图标文字轻量按钮）**：
   - `[法]` 签证与自驾法规（对应 2026 单次 eVISA 动态验证、715/1430 元使馆规费、1949 IDP 刑事法律生死线）。
   - `[行]` 跨地交通详单（20 个起讫区间票价、耗时、SmartEX 购票、特大行李预约、JR Pass 避坑）。
   - `[宿]` 住宿与 Airbnb（Tabelog 3.5 分则、Airbnb 民泊新法 M 执照验真、8 大区域精选房型、4 大铁律）。
   - `[备]` 行前推进清单（T-60 至 T-1 倒计时推进表、24h 应急热线）。
4. **Zone D（右侧引擎与全局设置，紧凑工具图标组）**：
   - **底图快选**：下拉单选框（CARTO 人文 / GSI 国土地理院 / OSM 全球开源）。
   - **暗色山峦 / 日间模式切换按钮**：一键切换沉浸式山地夜景或雅致和纸日间模式。
   - **底图密钥弹窗**：配置 CARTO API Key。
   - **版本矩阵入口**：快速呼出 5 大导览版本导航弹窗（v1 / v2 / v3 / v4 / wbd）。
