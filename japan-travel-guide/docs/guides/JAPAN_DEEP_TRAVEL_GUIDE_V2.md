## 1. v2 版本核心升级与设计哲学

在 v1 版本基础上，v2 版本依据 `japan_deep_travel_guide_2026_argon.md` 与 `japan_travel_web_design_spec_argon.md` 完成了重大架构级跃升：

1. **空间地理与时间日程深度共振（GIS-Driven Narrative）**：
   * 将散碎的文字路书转化为以**日本国土空间拓扑（本州山脉脊梁、日本海地质海岸、三陆与纪伊海蚀崖）**为轴线的可视化体系。
2. **双模交通动态切换矩阵（Dual-Mode Transport Sandbox）**：
   * 彻底打破传统攻略“非自驾即电车”的非此即彼，全面支持**【模式 A：干线铁道 + 地方私铁 + e-Bike 电助力单车/观光计程车】**与**【模式 B：合规自驾（含 ETC、高速周游券、山道难度、MapCode 与停车场定点）】**一键无缝比照。
3. **彻底摆脱外部地图 API 依赖（100% 离线自主渲染）**：
   * 针对国内网络环境下 Mapbox、Google Maps 甚至外部瓦片服务器可能出现的白屏、限流或鉴权失效风险，v2 网页版采用**内嵌式高精度日本列岛矢量地图引擎（Embedded SVG Cartography）**，确保在任何断网或无 Key 状态下毫秒级渲染。
4. **编辑级信息叙事与严禁 Emoji**：
   * 全流程遵循 Swiss-Japanese Grid（瑞士-和风平面排印），采用 Noto Serif SC、JetBrains Mono 与精准内联 SVG 矢量图标，彻底杜绝廉价表情符号。

## 2. 2026 赴日签证与自驾法律生死红线

### 2.1 刑事犯罪警示：中国大陆驾照在日驾驶的真相
> **【核心法律红线】**  
> 日本严格执行《1949 年日内瓦道路交通公约（Geneva Convention on Road Traffic 1949）》。  
> 1. **中国大陆机动车驾驶证（含任何国内电商平台代办的“国际驾照翻译认证件 / KRP / IDD 小册子”）在日本完全无效**！
> 2. 持上述伪证在日提车，正规租车公司（Toyota、Times、Orix）**一律严拒提车**；私下借车驾驶或私企租借上路，一旦遇警察盘查或轻微擦碰，将直接以**日本刑法“无免許運転（无照驾驶犯罪）”立案逮捕**，面临最高 3 年监禁或 50 万日元罚金，保险全额拒赔并列入永久遣返拒签黑名单。
> 3. **合规自驾唯一前提**：持有**中国香港、中国澳门、英国、美国、加拿大、澳大利亚等日内瓦公约缔约国/地区签发的正式驾照 + 当地官方核发的 1949 格式纸质 IDP 原件**；或中国台湾地区驾照配合 JAF（日本自动车联盟）官方日文译本。
> 4. **外免切替新政**：自 2025 年 10 月 1 日起，日本警察厅收紧外国驾照换领政策，必须提交当地《住民票》副本，持短期旅游签证已无法换领日本驾照。
> 5. **结论**：无上述海外资质者，**请坚定选用本指南的【模式 A: 公共交通微循环】**，准时、轻松且零法律风险。

### 2.2 15–20 日行程签证匹配预警
* 常规个人单次旅游签证默认停留期为 **15 天以内**。
* 若行程规划为 **16–20 天**，递签时**务必向指定代办机构明确申请“30 天单次电子签证（eVISA）”**，或申办**三年/五年多次往返签证**（单次停留 30 天/90 天）。若持有 15 天签在第 16 天离境，将被出入境管理局按非法滞留处理。
* **eVISA 核验规范**：持单次电子签出入境时，必须在手机浏览器**实时登录外务省官方系统展示带有动态倒计时与防伪二维码的网页**，严禁使用截屏、PDF 或纸质打印件。

| :--- | :--- | :--- |
| **骨干干线** | 新干线（早鸟票 Hayatoku 折扣） + 区域周游券（如关西广域、东北Pass、山阳山阴Pass） | 紧凑型混动车（Toyota Sienta）或 K-Car 轻自动车（N-BOX） |

| **导航与接驳** | Yahoo! 乘换案内查询精确站台番线与编成；黑猫宅急便办理宿场间行李轻装托运 | 车载导航输入 6–10 位 **MapCode** 或目的地电话号码；善用“道の駅”补给与休整 |

## 4. 三条 16–18 日历史地理与地貌深度大环线

### 路线一：【本州脊梁与千年古道】中山道宿场、北陆工艺、纪伊熊野纵贯线（18 日）
* **地理脉络**：穿越日本本州中央阿尔卑斯山脉，北达日本海工艺圈，南下纪伊半岛森林与海洋信仰圣地。
* **起讫口岸**：名古屋中部国际机场（NGO）进，大阪关西国际机场（KIX）出（完全不走回头路）。
* **里程与高程**：总移动 880 km，步道徒步 32 km，高程跨度 15m – 1505m（上高地）。
* **核心站点**：
  * D1–D2: 名古屋 ➔ 犬山城（现存最古天守） ➔ 美浓和纸（江户卯建防火山墙街区）
  * D3–D5: 木曾路（马笼宿 ➔ 妻笼宿 8km 森林石板路徒步 ➔ 奈良井宿千轩见世）
  * D6–D7: 松本城（国宝黑色天守） ➔ 安昙野山葵田 ➔ 上高地原生林（大正池至河童桥）
  * D8–D10: 奥飞驒温泉乡（野溪露天风吕） ➔ 飞驒古川 ➔ 五箇山相仓合掌集落 ➔ 金泽
  * D11–D12: 越前福井曹洞宗大本山永平寺（770年深山古杉） ➔ 琵琶湖西岸白须神社 ➔ 比叡山延历寺
  * D13–D14: 飞鸟明日香村（律令国家发祥地石舞台） ➔ 室生寺 ➔ 吉野山金峯山寺
  * D15–D17: 纪伊半岛：熊野古道中边路（发心门王子至本宫大社 7km） ➔ 汤之峰温泉壶汤 ➔ 那智瀑布
  * D18: 纪伊田边 ➔ JR 特急黑潮号沿海北上直抵关西机场返程

### 路线二：【山阴神话海岸与濑户内海群岛】出云古国、石见银山、四国遍路与岛波海道（17 日）
* **地理脉络**：贯穿本州西端阴阳两侧。山阴面向汹涌日本海，见证神话起点与古老采矿史；山阳与四国环抱温润平静的濑户内海。
* **起讫口岸**：冈山机场（OKJ）或关西机场（KIX）进出。
* **里程与高程**：总移动 940 km，步道徒步 28 km，高程跨度 10m – 1400m（四国喀斯特）。
* **核心站点**：
  * D1–D2: 仓敷美观地区（大原美术馆） ➔ 备中松山城（现存最高山城天守） ➔ 吹屋红墙矿山町
  * D3–D5: 水都松江（国宝天守、宍道湖落日） ➔ 足立美术馆（连续20年第一庭园） ➔ 出云大社（5.2吨巨注连绳）
  * D6–D7: 世界遗产石见银山（大森町、龙源寺间步） ➔ 运银古港温泉津温泉（夜神乐）
  * D8–D9: 津和野小京都 ➔ 萩市城下町（明治维新摇篮、松下村塾与武家白壁夏柑树）
  * D10–D12: 竹原老街 ➔ 坂道之城尾道 ➔ 岛波海道跨海骑行（生口岛耕三寺、大三岛大山祇神社国宝甲胄）
  * D13–D15: 松山道后温泉本馆 ➔ 内子木蜡老街 ➔ 四国喀斯特天狗高原 ➔ 祖谷溪藤蔓古桥
  * D16–D17: 琴平金刀比罗宫（1368阶朝圣道） ➔ 丰岛水滴美术馆 ➔ 经濑户大桥返回关西机场

### 路线三：【奥羽山脉与北国秘汤】东北陆奥潮风步道、出羽三山与绳文遗址巡礼（16 日）
* **地理脉络**：日本列岛北方最粗犷原生态的山海走廊，融合松尾芭蕉文学足迹、修验道与万年绳文文明。
* **起讫口岸**：仙台机场（SDJ）或东京羽田/成田进出。
* **里程与高程**：总移动 820 km，步道徒步 38 km，高程跨度 10m – 920m（酸汤温泉）。
* **核心站点**：
  * D1–D3: 杜之都仙台 ➔ 盐釜海鲜仲卸市场自选丼 ➔ 平泉中尊寺金色堂 ➔ 远野民间传说曲屋
  * D4–D5: 三陆复兴公园净土之滨白色海湾 ➔ 陆奥潮风步道种差海岸海滨草甸 ➔ 八户
  * D6–D8: 奥入濑溪流（14km苔藓与瀑布徒步） ➔ 十和田湖 ➔ 八甲田山 ➔ 三百年木造千人风吕酸汤温泉
  * D9–D10: 青森县立美术馆《青森犬》 ➔ 弘前城 ➔ 5000年三内丸山绳文遗址 ➔ 五能线白神号海景列车
  * D11–D13: 角馆黑板武家屋敷 ➔ 田泽湖 ➔ 乳头温泉乡（鹤之汤七汤巡礼）
  * D14–D16: 出羽三山羽黑山（2446级古杉石阶、国宝五重塔、斋馆精进料理） ➔ 宝珠山立石寺山寺 ➔ 山形新干线直达东京离境

## 5. 食宿高阶在地智慧（Tabelog 评测与秘汤/宿坊体验）

### 5.1 Tabelog（食べログ）评分使用法则
* **严苛的评分逻辑**：
  * **3.30–3.45 分**：当地市民日常口碑好店，食材新鲜、价格公道，极少踩坑。
  * **3.50 分以上**：位列全日本前 4% 顶尖水准的名店，往往拥有极高烹饪技艺。
  * **3.70 分以上**：多为米其林星级、百名店或需提前数月预约的殿堂级餐厅。
* **午市定食降维法则**：高级和牛料亭、割烹与鳗鱼饭老铺，晚市人均常达 15,000–25,000 日元，但在周中**午间定食仅需 1,800–3,500 日元**，食材同源，性价比极高。

### 5.2 住宿组合与宿坊体验
* **黄金比例**：全程 75% 晚数入住优质商务连锁（如 **Dormy Inn / 御宿野乃**，自带天然温泉大浴场与免费夜鸣拉面，人均 6,500–9,500 日元/晚；或 **东横 INN** 5,000 日元经济含早）。
* **宿坊（Shukubo）体验**：在比叡山延历寺会馆、出羽三山斋馆或永平寺柏树关留宿 1 晚，晨起参加住持根本中堂早课与坐禅，品尝纯正胡麻豆腐精进料理。
* **温泉汤治部**：在东北酸汤温泉或乳头温泉鹤之汤，选择朴素的“汤治部（自炊部）”，人均仅需 6,500–9,000 日元/晚即可享受完全相同的顶级白浊硫磺秘汤。
