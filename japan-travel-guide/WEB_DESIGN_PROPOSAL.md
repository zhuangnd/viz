# 日本深度自由行（15–20日）可视化交互导览网页版设计方案

*版本：v1.0 · 设计对象：中国大陆首次赴日深度自由行游客 · 交互与工程规格说明*

---

## 一、 产品定位与设计目标

### 1.1 定位
将冗长、复杂的跨区域长线旅行规划文档（涵盖签证核验、法律合规、三条16-18日骨干线路、复杂铁道通票体系及食宿预算计算），转化为**直观、沉浸、可操作的现代化交互式 Web 导览应用**。

### 1.2 核心目标
1. **空间地理清晰化**：通过高精度地图（Leaflet + CartoDB 高雅图层）直观呈现路线走向、山海走势及铁道交通枢纽，解决初次访日者对日本地理与新干线网缺乏空间感知的问题。
2. **多维动态筛选**：支持在 **3条经典深度路线** 与 **2大核心旅行季节（1-2月雪国温泉 vs 9-10月秋叶自然）** 间无缝动态切换，地图路径与日程说明联动更新。
3. **法律风险与关键规则前置**：以高对比度、友好但醒目的交互卡片，明确揭示“中国大陆驾照在日无法自驾（涉无照驾驶犯罪）”及“15-20天行程必须申请30天签证”两大生死红线。
4. **精细化预算可视化**：提供可交互的“15–20日动态预算测算器”，支持天数微调、住宿偏好与出行模式组合，实时生成资金构成环状/条形图表及明细。
5. **视觉与工程标准**：**零 Emoji**，采用全矢量 SVG 精致图标系统；采用极简和风现代排版；完全响应式适配桌面（1440px+）、平板（768-1024px）与移动端（375-430px）。

### 2.2 图标规范（严格执行“禁止 Emoji，优先 SVG”）
* 所有交互节点、交通方式（列车、巴士、步行）、食宿分类（餐食、床铺、温泉、日元）、预警状态均采用内联无损 `<svg viewBox="0 0 24 24">` 图标。
* 描边粗细统一为 `1.75px` 或 `2px`，转角平滑，保持极简现代线框风格（Lucide/Feather 体系）。

### 2.3 字体排印（Typography）
* 标题字体：优先匹配系统高质量宋体/明朝体（`"Noto Serif SC", "Source Han Serif SC", STSong, serif`），呈现东方传统人文质感。
* 正文字体：采用高可读性非衬线体（`system-ui, -apple-system, "Noto Sans SC", "PingFang SC", sans-serif`），行高统一设定为 `1.7`。

## 四、 核心交互模块规格说明

### 4.1 模块一：交互式地图与路线联动引擎 (Map & Route Engine)
* **技术选型**：Leaflet.js + CartoDB Voyager 极简清晰底图。
* **数据结构**：每条路线定义包含地理坐标序列（经纬度）、站点层级（首发站、新干线换乘站、景点散步站）、推荐交通工具代码及关联文化地标。
* **联动机制**：
  1. 用户切换顶部路线选项（路线 A、B、C），地图视口通过平滑飞行动画（`flyToBounds`）自动重置缩放范围，并渐变重绘航线。
  2. 点击地图上的任何车站标记，右侧日程面板自动平滑滚动并高亮该日对应的行程卡片；
  3. 反之，在日程面板悬停或点击某一日日程，地图自动对焦并弹开该日重点景点的交互气泡。

### 4.2 模块二：双季动态适配器 (Seasonal Adapter)
* 针对 1–2月（冬雪与秘汤）与 9–10月（早秋与自然），设置一键切换状态：
  * **切换至 1–2月**：界面自动注入雪季专属提示（防滑装备要求、JR大雪延误备案、树冰/雪见温泉高亮、上高地冬季闭山避坑提醒）。
  * **切换至 9–10月**：界面动态切换为秋季模式（早秋登山徒步适宜度、奥入濑溪流赏枫时段、松茸与秋刀鱼旬物时令推荐）。

### 4.3 模块三：15–20日动态预算测算器 (Budget Calculator)
* **交互控件**：
  * 天数微调滑动条（15 天 – 20 天）。
  * 消费档次单选框（经济背包型 / 经典舒适型 / 品质深度型）。
  * 是否包含温泉旅馆体验晚数（0晚 / 1晚 / 2晚 / 3晚）。
* **动态计算引擎**：
  * 基于当前日元实时汇率波动模型，细分计算：
    * 机票区间（预估）
    * 签证与保险
    * 城际交通与区域铁路周游券（固定通票成本 + 市内 IC 充值按日累加）
    * 酒店住宿（根据选定天数与档次动态累乘，叠加温泉一泊二食差额）
    * 每日餐费（早餐 + 午市定食 + 晚间特色居酒屋/拉面）
    * 门票、美术馆与文化见学杂费
  * 实时生成：人民币总预算（¥）、折合日元（円），以及分项柱状占比进度条。

### 4.4 模块四：签证与法规合规“红线抽屉” (Compliance Modal)
* 针对初次赴日人群高频犯错的痛点，常驻“合规红线与须知”按钮，点击呼出全屏抽屉面板：
  * **红线一【自驾法律禁区】**：全面阐述中国大陆驾照及网络翻译件在日属无证驾驶的法律责任，展示正规合法持证要求，引导使用成熟的 JR/私铁系统。
  * **红线二【停留期危机】**：图解 15 天与 30 天签证的差异，避免因订购 16 天往返机票而因 15 天签造成非法滞留。
  * **红线三【现金与支付】**：列出只收现金的场景清单（老街拉面店、神社御朱印、投币洗衣机）。

## 五、 技术栈与工程实现

* **架构原则**：无外部重型前端框架依赖（零构建步骤，直接双击或静态托管即可运行）。
* **核心类库**：
  * HTML5 + CSS3（Grid/Flexbox 响应式排版 + 纯原生 CSS 变量系统）。
  * Leaflet.js（轻量级高性能开源地图库，CDN 加载）。
  * SVG 图标系统（内联无损矢量图，无额外网络请求与闪烁）。
  * 原生 ES6+ JavaScript（包含状态管理、地图交互、计算器反应式更新）。
* **兼容性与性能**：
  * 完全支持 Chrome、Safari、Edge 及主流移动端浏览器（iOS Safari、Android Chrome）。
  * 首屏秒开，无多余大体积图片阻塞。
