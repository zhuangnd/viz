# 日本深度自助旅行（15–20日）空间交互导览系统

本项目专为首次赴日、计划进行 **15–20 日深度自由行** 的中国大陆旅行者打造，告别小红书滤镜与营销化套路，立足日本外务省、JNTO观光厅、JR铁道官方及日本在地人文地理视角，提供全景地图、文化脉络、合规自驾与公共交通双模式、D3海拔高程剖面、在地食宿与实时预算测算。

## 三、v3 旗舰版核心亮点与升级

### 1. 经典文化溯源：浮世绘《富岳三十六景》与葛饰北斋灵感线
- **东京发端**：探访上野【东京国立博物馆】（法隆寺宝物馆）与墨田区妹岛和世设计的【墨田北斋美术馆】，瞻仰《富岳三十六景·神奈川冲浪里》与《凯风快晴（红富士）》原版拓印。
- **浅间山麓**：北陆新干线直达轻井泽，对照《富岳三十六景·信州浅间山》火山意象与中山道旅情。
- **小布施晚年圣地**：葛饰北斋 83 岁高龄隐居信州栗之乡，参访【北斋馆】（屋台天花板《怒涛图·男浪女浪》真迹）与【岩松院】（21 叠榻榻米绝笔天井画《八方睨之凤凰图》）；参拜【国宝善光寺】体验漆黑“戒坛巡礼”。
- **自然与国宝**：现存最古老五重六层木造天守【国宝松本城】、安昙野黑泽明《梦》水车山葵田、北阿尔卑斯神降之地【上高地】梓川与大正池（海拔 1,505m）。
- **世界遗产与名都**：避开过度商业化的白川乡，探访原始纯朴的世界文化遗产【五箇山·相仓合掌集落】；加贺百万石名都【金泽】兼六园雪吊挂与 21 世纪美术馆；越前曹洞宗大本山【永平寺】156 幅天井花鸟图与日本海【东寻坊】绝壁；关西千年古刹【三十三间堂】千尊千手观音立像与宇治【平等院凤凰堂】。

### 2. 地图引擎高可用与多源底图容灾
- **CARTO Voyager（默认推荐）**：系统已内置有效 API Key，渲染高精度、优雅人文色调的矢量栅格底图。
- **CARTO Positron**：极简浅色底图，提供极高对比度的路线轨迹展示。
- **日本国土地理院 (GSI) 官方标准图 & 淡色地形图**：直接调用日本官方地理测绘数据，等高线与铁道路网精准清晰。
- **OpenStreetMap 全球开源底图**：免 Key 双源容灾兜底保障。
- **底图密钥自定义弹窗**：支持旅行者输入自有 CARTO Key 或一键重置为系统默认 Key。

### 3. 2026 出入境政令与自驾合规核心提示
- **Visit Japan Web (VJW) 统一申报**：2026 起入境审查（外国人入国记录）与税关申报（携带品申告）合并为单一 QR 码，支持出境前线上申报并保存离线码。
- **eVISA 在线验真准则**：值机与入国核验时，必须在手机联网环境下登录展示带有动态倒计时的 `Visa Issuance Notice` 页面（任何截图或 PDF 打印均无效）。
- **严正自驾法务红线**：中国大陆驾照、公证件、翻译件及国内平台所谓“国际驾照认证件”在全日本**均不具备法律效力**，私自驾驶触犯《道路交通法》第64条（3年以下惩役或50万日元罚金并驱逐出境）；合法自驾唯一途径为**日内瓦 1949 IDP 原件**（或台湾驾照+JAF日文译本）。
- **车载导航专用检索**：每个自驾节点均提供精确的 **MapCode** 与车载 GPS 专用电话号码（**TEL**），彻底解决日文输入困难。

### 4. 应急与实用工具集
- **行前备忘 Checklist**：证件、支付（Apple Wallet 绑定 Suica/ICOCA、2-3万日元现金与硬币储备）、电器（100V两脚扁平插头通用、移动电源严禁托运）、随身常备药与垃圾分类自律规范。
- **全天候紧急求助通讯录**：日本观光厅多语种访日热线（050-3816-2720，提供24小时中文服务）、警察 110、急救/火警 119、中国驻日使领馆紧急领保专线。
- **送签滞在予定表导出**：一键生成符合日本驻华使领馆规范的《Schedule of Stay》，支持浏览器直接打印或导出 PDF。

### 5. 严格规范设计
- 严格遵循**无 Emoji 表情**设计原则，全量采用清晰、轻量化的内联 **SVG 图标**，保证跨平台（Windows / macOS / iOS / Android）渲染一致性与高雅典雅的视觉品质。

## 四、本地运行与调试

本项目为纯前端静态工程，无需任何后端服务或依赖安装：

1. **直接双击打开**：用现代浏览器（Chrome、Edge、Safari、Firefox）直接双击打开 `v3.html` 即可畅享完整交互。
2. **本地静态服务（推荐）**：
   ```bash
   # 在当前目录下启动轻量 HTTP 服务
   python3 -m http.server 8080
   # 访问地址：http://localhost:8080/v3.html
   ```
3. **重新构建 v3.html**：
   ```bash
   python3 scripts/build_v3_html.py
   ```
