## 一、 项目背景与设计理念

本作品基于微信公众号深度长文，旨在将静态的长篇美食图文升华为**具备国际获奖级（Awwwards / FWA 评选标准）的数字化、杂志级、高交互美食可视化网页**。

泉州作为古代“海上丝绸之路”的起点，饮食文化既有中原古风，又具南洋与中东香料风韵，讲究“清、香、爽、鲜”。本设计以“**刺桐古韵，山海馔玉**”为美学母题：
- **色彩体系**：闽南古厝胭脂红砖（`#9E3524`）、深海黛青（`#112832`）、海丝古铜金（`#B8853B`）与纸本宣白（`#F9F7F1`）。
- **设计守则**：严格执行**零 Emoji 原则**，全站采用定制化精细内联 SVG 矢量图标；采用非对称杂志网格排版系统与呼吸感留白。
- **微交互与质感**：纸实质感微粒噪点底纹、丝滑瓷碗蒸汽动效、多维风味指数雷达、实时品鉴评语引擎。

## 二、 核心功能与交互矩阵

### 1. 全域珍味图谱（20+ 绝味名吃全景收录）
涵盖文章涉及的五大核心风味体系，不遗漏任何细节：
*   **壹 · 主食配菜二合一**：泉州面线糊（大骨汤 vs 鱼骨汤两派）、泉州咸饭（葱油五花肉芥菜底）、泉州卤面。
*   **贰 · 牛肉原动力**：闽式咖喱牛排、牛肉羹/清汤、一人食牛肉三件套、晋江王贼/石狮林东升/安海大华福记老饕牛肉巡礼。
*   **叁 · 地瓜的报恩**：外酥里嫩炸醋肉、安海正宗菱形菜粿、石狮老街王记润饼菜（加入麻粩的绝密配方）、深沪拳头母。
*   **肆 · 山海味觉暴击**：二十年老店忠记炭火盐烧姜母鸭、晋江安海纯天然星虫土笋冻、石狮城隍马脚桥肉粽与夜市约记炕肉粽、现剥珍珠蚵仔煎、崇武鱼卷与深沪水丸。
*   **伍 · 石花膏与蜜水**：天后宫百年秉正堂四果汤（百花蜜水与蜜芋头）、爱啊石花膏、西街满煎糕、古法蒜蓉枝、后城老街绿豆饼与永春达埔麻粩。

### 2. 「面线糊自选调配实验室」(Interactive Noodle Lab)
- **汤底流派自由切换**：鱼骨清鲜派（县后街代表）与大骨浓汤派的汤色动态渐变与纹理渲染。
- **料头自选池**：自选炸醋肉、卤大肠、剪段酥油条、鲜海蛎、炸五香、鸭血等 9+ 种名点，料头实时落入动态瓷碗，激活动态蒸汽与浮标。
- **实时价格与老饕评语引擎**：根据所选料头组合，实时计算价格并输出地道泉州老饕的风味品评。

### 3. 「一人食牛肉三件套解构台」(Beef Trio Deconstructor)
- 交互解构泉州午间市井的黄金组合：芥菜咸饭、闽式咖喱牛排、姜丝牛肉羹。
- 深度拆解海丝香料溯源、古法工艺奥义与老饕品鉴心法。

### 4. 「四大深度寻味专线」(Tasting Routes)
从古城一路逛到石狮、晋江与崇武：
- **路线甲 · 鲤城古城骑楼散策**（面线糊 → 咖喱牛排 → 秉正堂石花膏 → 忠记姜母鸭）
- **路线乙 · 晋江安海老饕探秘**（大华福记牛肉 → 安海长兴土笋冻 → 桥头菜粿）
- **路线丙 · 石狮城隍烟火巡礼**（王记润饼菜 → 马脚桥肉粽 → 林东升牛头狮 → 约记大仑街夜市）
- **路线丁 · 崇武深沪向海讨鲜**（深沪水丸与拳头母 → 海鲜焖咸饭 → 崇武现煎鱼卷）

### 5. 「我的泉州寻味护照」(Foodie Passport)
- 本地 `localStorage` 持久化收藏心仪美食。
- 探索收集进度实时反馈（“已解锁 X/20 处绝味”）。
- 支持一键**打印 / 导出私人定制寻味手账**（专属 Print 打印机排版优化）。

## 四、 本地运行与浏览方式

由于采用现代纯前端原生技术栈（Vanilla Modern Web），无需任何繁重构建步骤：
1. **直接双击打开** `index.html` 即可在任意现代浏览器中畅享体验；
2. 或在本项目目录下启动简易本地服务：
   ```bash
   python3 -m http.server 8000
   ```
   随后在浏览器访问 `http://localhost:8000` 即可。
