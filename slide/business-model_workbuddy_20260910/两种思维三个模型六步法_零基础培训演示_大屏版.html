拆解
结构化思维 → 问题模型
业务原话：
"今年出口贸易增长乏力，得查查怎么回事。"

三个拆解动作

跟谁比？

去年同期 / 全国均值 / 兄弟关

乏力在哪？

国家、HS 大类、企业、贸易方式

为什么乏力？

量？价？结构变了？

拼成公式

出口贸易额 = Σ 各 HS 编码 × 单价 × 数量 同比增长率 = (本期 − 同期) ÷ 同期 乏力归因 = 量贡献 + 价贡献 + 结构贡献

验证
工程化思维 · 可验证
不要先激动。先验，再解读。
  • ✓
    行数核对 — 工具数 = 月报数

    空值检查 — 关键空值占比 ＜ 0.5%
  • ✓
    极值检查 — 确认不是录错
  • ✓
    抽样回溯 — 随机抽样回原系统比对

分析
工程化 → 结构化 → 表 + 图 + 三句话

产出三件套

空间拆

"下滑 60% 集中在机电产品，
前 3 个 HS 大类贡献了 8 成。"

因果拆

"量贡献 -2.1pp、价贡献 -1.5pp——
量价齐跌是主因。"

主体拆

"中小企业 -15%，头部 +6%，
集中度在上升。"

SQL 跑得动是工程化，能讲清楚为什么下滑则是结构化思维。

报告
结构化思维 · 回译闭环

汇报三步法

第一步 · 拆解
"增长乏力，拆开看，主要来自三个维度——
HS 大类、国别、企业。"
第二步 · 模型
"量贡献 -2.1pp、价贡献 -1.5pp、结构 +0.4pp——
量价齐跌是主因，结构升级是亮点。"
第三步 · 方案
"建议下一步分三条线核实。"
业务点头了，6 步才算闭环。
只会念节点名，翻译链就是断的。

避坑清单
