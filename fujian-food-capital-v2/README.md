## 一、 项目背景与全新定位 (v2)

本版本为**独立重塑、全新产出版本**（位于 `viz/fujian-food-capital-v2`）。彻底摒弃了常规网页“块状卡片 + 线性长页面滚动”的呆板排版，以**空间、时间、叙事、哲学与路径**五个独立但数据实时互通的沉浸式视域，全方位呈现泉州“半城烟火半城仙”的城市饮食灵魂。

### 核心规格统计
* **8 大原版章节**：严格遵照原著 PDF 标题卡（主食配菜二合一、地瓜的报恩、牛肉原动力、小海鲜盛宴、咸甜羹汤相斗阵、闽南天妇罗、烧酒客烧酒配、糕粿茶配伴手礼）
* **52 处世遗珍味**：100% 完整录入原文所有菜品、风味特征与原著金句
* **50 家真实食肆**：跨越 6 大地理板块（鲤城古城、石狮老街、晋江安海、晋江深沪、晋江张林、丰泽蟳埔）

## 二、 五大创新交互视域

1. **视域 Ⅰ ·【刺桐山海图 · 空间拓扑沙盘】**
   * 手绘工笔风矢量山海地图：戴云山脉、晋江古航道、台湾海峡与海岸浅滩。
   * 50 家店铺精确拓扑落点，按“本地力荐、百年老字号、隐世小店、夜宵排档、标杆名店”赋予专属光晕。
   * **一键点亮夜市灯火模式**：全图变暗，白天摊位隐去，深夜排档与面线糊亮起夜市灯笼光晕。
   * 点击店铺，侧边滑出**“食肆牌匾卡”**，展示探店实录与招牌名点。

2. **视域 Ⅱ ·【人间十二时辰 · 市井时序光轨】**
   * 24 小时交互日晷刻度滑块（破晓晨炊 ➔ 晌午正席 ➔ 闽南茶配 ➔ 暮色大席 ➔ 暗夜排档）。
   * 全页面环境光与色调随时间动态流转（晨曦暖白 ➔ 日正赤红 ➔ 暮色黛青 ➔ 子夜深墨）。

3. **视域 Ⅲ ·【八重风味长卷 · 电影画幅解构剧场】**
   * 8 大原版标题卡横轨切换，保留原著核心命题与引语。
   * 食材工艺交互解构展示台（如面线糊粉浆悬浮力学、地瓜引种报恩谱系、海丝香料烹牛柜等）。

4. **视域 Ⅳ ·【神凡山海谱 · 风味多极引力星盘】**
   * 以「山 ↔ 海」为横轴、「咸 ↔ 甜」为纵轴构建 52 味美食的天体引力星图。
   * 支持按“海丝香料、神明供桌、迷之半甜咸、大味至简、一人食神装”一键拉出金色引力光索。

5. **视域 Ⅴ ·【老饕风味动线 · 策展漫游】**
   * 4 条可自动步进的漫游动线（古城一日、出城去石狮、晋江乡镇老饕线、深夜镬气线）。
   * 支持“开启自动漫游”，沿路逐站高亮推进。

## 三、 规范与运行方式

* **绝对零 Emoji 规范**：全站所有标志、星盘、图例均采用手绘精细内联 SVG 矢量图标。

* **本地预览**：双击 `index.html` 或运行本地 HTTP 服务访问。
