# rail-doubao · 高铁动车路线图查询与可视化平台

独立项目目录。本项目的全部产物与代码均在本目录内自建，不引用其他目录的任何已有文件或代码。

## 项目定位

面向任意指定站点，聚合其全部**始发 / 终到 / 途经**的高铁（G）、动车（D）、城际（C）车次，以地图形式呈现每条线路的经停站点、到发时刻与区间时长，支持按站点多维度检索与线路联动查看。

## 数据源与合规要点

- 主数据源：12306 车站车次查询（`czxx/query`，**当前服务端 404 失效**）→ 替代链路 `leftTicket/queryG`（站到站车次列表）＋ `czxx/queryByTrainNo`（经停序列）。
- 站点代码表：`kyfw.12306.cn/otn/resources/js/framework/station_name.js?station_version=1.9374`（3,388 条；旧路径 `station_name_v10036.js` 已失效）。
- 电报码以官方字典为准：**厦门北=XKS、厦门=XMS、冠豸山=GPS、冠豸山南=GSS**（第三方旧资料「厦门北=XMS」有误）。
- 补充：OSM 铁路几何（线路走向）、第三方授权 API（交叉校验 / 生产备选）。
- 采集原则：低频、节流、可追溯；默认仅个人 / 内部研究与原型演示，公开发布或商业化前须切换授权数据渠道并通过地图合规审查。

## 阶段 1 结论（详见 docs/阶段1-数据可行性验证报告.md）

- 会话、站点字典、站到站列表（queryG）、经停序列（queryByTrainNo）、交叉校验 **均可行**；当前无需验证码（`openRandCodeCheck='N'`）。
- **受限项**：`czxx/query`（指定站点全量车次）服务端 404（无头与真实浏览器同证）→ 官方直取通道不可用，待官方恢复（监控）或切换第三方授权 API 兜底。
- 样例数据：厦门北 7 条线路（G1316/G1638/G1622/D3212/G1640/G2372/G2278），含完整经停表（10–25 站）。

## 阶段 2/3 试点结论（厦门北，2026-09-22/23）

- **数据**：`leftTicket/queryG + czxx/queryByTrainNo` 采集 7 个 O-D、**31 条线路**（厦门北 30 条：始发 8 / 终到 5 / 途经 17；厦门 16 条；冠豸山南 5 条），含完整经停与到发时刻。
- **坐标**：OSM Nominatim 按站地理编码 + 严格主词校验 + 线路孤立点距离过滤 → **184/198 站已定位**；14 站未定位（OSM 未收录小站/错位剔除，如瑞金、于都、利川、遵义、荆州等），页面按“未定位·仅列示”处理，线路为相邻已定位站点连线示意。
- **数据口径**：冠豸山（GPS）方向查询在官方数据中返回冠豸山南（GSS）车次，以官方返回为准；K244 等普速按“全程起讫 + 本段区间时刻”双口径展示。
- **页面 v1/v2**：`web/高铁动车路线图.html` 单文件（数据内嵌），支持枢纽切换、始发/终到/途经筛选、车次→地图高亮→经停表联动、站点弹窗查看到发；底图三级回退（OSM → CARTO → 高德路网）。
